# worker/generate/rule_judge.py

- **한 줄 설명**: 판단해보기 주관식 근거를 키워드·연결어 규칙으로 루브릭 9점(증거 0~2·추론 0~4·반박 0~3)으로 채점하고 100점으로 환산한다.
- **입력**: 답안 문장, 카드의 `key_facts`(`[{"text", "keywords": [...]}]`, **형식 초안, C와 맞출 것**), 인과 경로 개념 `chain`(`[{"name", "aliases"}]`, concepts 행 순서대로), (선택) 판단을 뒤집을 다른 힘 개념 `counter`(같은 형식).
- **하는 일**: 띄어쓰기를 무시하고 키워드를 찾는다. 단계 정의(기술확정안 "루브릭", 9점)를 키워드로 근사한다.
  - 증거: 사실 0개 → 0, 1개 또는 연결어 없이 2개 이상 → 1, 2개 이상 + 연결어 → 2
  - 추론(SOLO): 개념 0 → 0, 1 → 1, 2개 이상 연결어 없음 → 2, 2개 이상 + 연결어 → 3, 거기에 반박 문장이 아닌 곳에서 조건·상황(만약·~라면·~경우)으로 일반화 → 4
  - 반박(Osborne): 반대 표현이 있는 문장만 본다. 반대 표현만 → 1, 그 뒤에 요인(개념·사실·counter) 1개 → 2, 서로 다른 요인 2개 이상 → 3 (같은 개념의 다른 이름은 1개)
- **출력**: `RuleResult(rubric, total, score, matched_facts, matched_concepts)`. score = round(합계 / 9 × 100). 60점 이상이면 서버가 맞음으로 기록한다(P17, 6점 = 67점).
- **주의할 점**: Claude 채점(judge.py, 4주차)이 실패할 때 쓰는 대체 수단이다. 증거는 Claude 채점 때도 이 코드로 매긴다(기술확정안 "증거: 코드"). 규칙은 보수적이라 '~돼서', '~어서' 같은 어미는 연결어로 세지 않고, '~되면'은 일반화로 보지 않는다. 증거 2점의 "+ 연결어" 조건은 B 제안이고 #16 정의(사실 2개 이상)보다 엄격하다(확정 필요). 연결어·반대 표현 목록은 κ 확인(8주차) 때 고칠 수 있다. 금지 표현 검사는 B의 validators 몫이다.
- **테스트**: `python -m pytest tests/test_rule_judge.py -q` (손계산 답안: 만점 9/9 → 100, 조건이 반박 문장에만 있으면 추론 3, '~되면'은 일반화 아님, 개념만 → 2/9 → 22, 사실 2개 연결어 없음 → 증거 1, 반대 표현만 → 반박 1, 같은 요인 두 번 → 반박 2, 빈 근거 → 0. 환산 6 → 67, 5 → 56).
