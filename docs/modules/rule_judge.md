# worker/generate/rule_judge.py

- **한 줄 설명**: 판단해보기 주관식 근거를 키워드·연결어 규칙으로 루브릭 9점(증거 0~2·추론 0~4·반박 0~3)으로 채점하고 100점으로 환산한다.
- **입력**: 답안 문장, 카드의 `key_facts`(`[{"text", "keywords": [...]}]`, **형식 초안, C와 맞출 것**), 인과 경로 개념 `chain`(`[{"name", "aliases"}]`, concepts 행 순서대로).
- **하는 일**: 띄어쓰기를 무시하고 키워드를 찾는다.
  - 증거: 사실 0개 → 0, 1개 또는 연결어 없이 2개 이상 → 1, 2개 이상 + 연결어 → 2
  - 추론(SOLO): 개념 0 → 0, 1 → 1, 2개 이상 연결어 없음 → 2, 2개 이상 + 연결어 → 3, 3개 이상 + 연결어 2개 이상 → 4
  - 반박: 반대 표현이 있는 문장만 본다. 반대 표현만 → 1, 그 뒤에 다른 힘(개념·사실) → 2, 거기에 조건(만약·~라면·~경우) → 3
- **출력**: `RuleResult(rubric, total, score, matched_facts, matched_concepts)`. score = round(합계 / 9 × 100). 60점 이상이면 서버가 맞음으로 기록한다(P17, 6점 = 67점).
- **주의할 점**: Claude 채점(judge.py, 4주차)이 실패할 때 쓰는 대체 수단이다. 증거는 Claude 채점 때도 이 코드로 매긴다(기술확정안 "증거: 코드"). 규칙은 보수적이라 '~돼서', '~어서' 같은 어미는 연결어로 세지 않는다. 연결어·반대 표현 목록은 κ 확인(8주차) 때 고칠 수 있다. 금지 표현 검사는 B의 validators 몫이다.
- **테스트**: `python -m pytest tests/test_rule_judge.py -q` (손계산 답안 5개: 만점 9/9 → 100, 개념만 → 2/9 → 22, 사실 2개 연결어 없음 → 증거 1, 반대 표현만 → 반박 1, 빈 근거 → 0. 환산 6 → 67, 5 → 56).
