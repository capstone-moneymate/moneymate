## CSV 형식

| 파일 | 컬럼 | 규칙 |
| --- | --- | --- |
| concepts.csv | `id,name,theme,kind,aliases` | `id`는 영문 소문자+밑줄. `aliases`는 `;`로 구분 (DB에서는 `TEXT[]`) |
| causal_edges.csv | `from_concept,to_concept,force_dir,note` | `force_dir`는 `up`(올리는 힘) / `down`(누르는 힘). "from이 커지면 to를 올린다/누른다"로 읽는다 |

`kind`는 4가지: `event`(사건) / `indicator`(지표) / `outcome`(결과) / `signal`(차트 신호)

### 동결 → 성장주

설명 흐름: 동결(시장은 인하 기대) → 시장금리 높게 유지 → 할인율 ↑ → 성장주 ▼. 앞부분과 뒷부분을 다른 자료가 받친다.

| 연결 | 근거 | 출처 |
| --- | --- | --- |
| 동결(시장은 인하 기대) → 성장주 가치평가 ▼ | **예상과 다른** 금리 정책에 주가가 반응한다. 시장이 동결을 예상했다면 이 힘은 약하다 | Bernanke & Kuttner (2005), *Journal of Finance* 60(3) |
| 시장금리 ↑ → 성장주 가치평가 ▼ (`bond_yield → growth_valuation`) | "할인율 영향이 큰 성장주 위주의 나스닥지수 상대 성과는 금리변화와 음의 관계" (2020년 4분기 관찰, 나스닥 회귀 기울기 −10.9, R² 0.397) | 자본시장연구원 「2021년 경제 및 자본시장 전망」(2020.11.25) 24쪽 |
| (메모) 실적 성장이 강하면 상쇄될 수 있다 | "경기 회복이나 기업실적개선은 주가 상승 요인 ⇔ 금리 상승은 할인율 증가로 주가에 부정적" | 자본시장연구원 (2020) 24쪽 |
| (보조) | 금리와 성장주 관계 해설 | U.S. Bank (2026.9.18) |

- 자본시장연구원 2021년 전망은 2020~21년 코로나 이후 경제 정상화 시기를 분석한 것이므로 "그 시기에 관찰된 관계"로 인용한다. 23쪽은 S&P500 수익률 분해 **그림만** 있고 문장이 없어 문장 근거로 쓰지 않는다.

### 금리 인하 → 시장금리 → 성장주

| 연결 | 근거 | 출처 |
| --- | --- | --- |
| 기준금리 인하 → 시장금리 ▼ (`rate_cut → bond_yield`) | "무위험 할인율은 기준금리 인하의 영향으로 하락" | 자본시장연구원 KCMI Economic Outlook 2018년 하반기 Ⅲ-2 「한ㆍ미 주식시장 전망」 94쪽 각주 27 |
| (메모) 할인율과 주가 | "할인율이 증가(하락)할수록 주가는 하락(상승)" | 같은 보고서 92쪽 |
| (메모) 왜 성장주가 더 민감한가 | "성장주는 가치주 보다 금리 변화에 민감 … 먼 미래에 실현될 이익의 중요성이 높기 때문에 … 할인율의 변화에 민감" | 같은 보고서 99쪽 (Lettau and Wachter 2007; Campbell, Polk and Vuolteenaho 2010 인용) |
| 시장금리 ▼ → 성장주 ▲ (`bond_yield → growth_valuation`의 반대 방향) | "금리가 상승하면 가치주가 성장주 대비 우수한 성과를 보이며, 반대로 금리 하락기에는 성장주 성과가 우수한 경향" (1975~2018년, 10년 만기 국채 금리 기준) | 같은 보고서 101쪽 |
| ⚠️ 조건 | "둔화 및 침체 국면에서는 기준금리 인하의 영향으로 무위험 할인율이 하락세를 유지하는 반면, 경기부진의 영향으로 경제주체의 위험회피도가 증가하여 ERP가 크게 확대" → 전체 할인율이 오히려 오를 수 있다 | 같은 보고서 94쪽 |

- **경기 침체 때문에 금리를 내리는 시기**에는 주가가 오히려 내릴 수 있다. 그래서 금리 인하 → 성장주를 직접 잇지 않고 시장금리 경로로 설명하고, 조건은 `bond_yield → growth_valuation` note에 적는다.
- 보고서 정식 제목·발간일은 표지에서 확인 후 보완한다.

## 연결하지 않은 것

| 후보 연결 | 연결하지 않은 이유 | 메모 |
| --- | --- | --- |
| HBM 공급 확대 → 메모리 가격 ▼ | 초안은 "공급이 늘면 가격이 내린다"는 일반 원리로 넣었으나, 근거를 찾지 못했고 실제 자료는 반대(▲) 방향이다 | HBM을 더 만들수록 범용 D램 생산이 줄어든다 (위 TrendForce 자료) |
| 기준금리 인하 → 성장주 가치평가 ▲ (직접) | 경기 침체로 금리를 내리는 시기에는 위험 프리미엄이 더 커져 주가가 내릴 수 있어(자본시장연구원 KCMI 2018 하반기 94쪽), 조건 없는 정답으로 쓰기 위험하다. 경로(→ 시장금리 ▼ → 성장주 ▲)로 설명한다 | |
| HBM 공급 확대 → 반도체 기업 실적 ▲ (직접) | 두 자료 모두 실적 상승의 이유를 "공급 확대"가 아니라 "가격 상승"으로 설명한다. 이미 있는 경로(→ 범용 메모리 가격 ▲ → 실적 ▲)로 충분하고, 연결이 줄어 학습자가 덜 헷갈린다 | |
| 동결 → 예대금리차 ▲ | 원문은 금리가 **오르는(내리는)** 시기의 확대(축소)만 확인한다. 동결은 변화가 없으므로 화살표를 두지 않는다 | 기준금리 **수준**이 높을수록 잔액 예대금리차 **수준**도 높다 (이슈노트 9쪽 <표 1>, 계수 +0.245, 전분기 말 기준금리 수준 → 분기 말 예대금리차 수준). 높은 수준에서 동결하면 예대금리차는 높게 유지되지만 확대되지는 않는다 |
