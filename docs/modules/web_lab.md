# 분석 자료 탭 (web/src/pages/lab: LabPage.tsx · LabQuizPage.tsx · labData.ts · labProgress.ts)

**한 줄 설명**: 13F·액티브 ETF·실적 발표 같은 자료를 읽는 법을 개념 한 장 + 퀴즈 한 문제로 익히는 탭 (UI 시안 app.html 의 "분석 자료").

**입력**
- `labData.ts`: 화면에 들어 있는 고정 내용. 기초 자료 6개(`LAB_TOPICS`)와 큰손 기록 문제 3개(`LAB_RECS`). 서버에서 받지 않는다.
- `labProgress.ts`: 이 기기의 localStorage (`mm:lab:<사용자 ID>`).
- 연속 학습 일수만 서버 값(`useSummary`)을 읽는다.

**하는 일**
- `LabPage`(/lab): 자료 종류 칩과 검색으로 거르기, 아직 안 푼 첫 자료를 배너로, 기초 자료·큰손 기록을 가로 카드로 보여 준다.
- `LabQuizPage`(/lab/topic/:id, /lab/rec/:id): 기초 자료는 개념 → 문제, 큰손 기록은 고른 문제부터 남은 문제까지. 문제 종류는 객관식·O/X·빈칸 채우기·짝 맞추기·순서 맞추기.
- 아래 버튼은 [잘 모르겠어요] [확인]. 채점은 화면이 한다(정답이 `labData.ts` 에 있다). 9개를 다 풀면 완료 화면.

**출력**: 화면과 localStorage 기록(`{자료 id: {st: 'started' | 'done', ok}}`). 서버·DB 에는 아무것도 쓰지 않는다.

**주의할 점**
- **큰손 기록 3문제의 종목·숫자는 학습용 예시이고 실제 공시 값이 아니다.** 화면에 "학습용 예시"라고 적어 두었고, 시안에 있던 실제 인물·ETF 이름은 뺐다. 실제 값으로 바꾸려면 탭2 겹침 데이터(`/api/overlaps`)로 문제를 만들어야 한다.
- 진행 기록은 기기에만 남아서 다른 기기·브라우저에서는 처음부터다. 마이페이지의 달력·연속 학습에도 들어가지 않는다.
- 이 탭의 답은 지식 상태(BKT)·복습에 반영되지 않는다.
- 탭2(13F·ETF, `SHOW_TAB2`)와는 별개 탭이다.

**테스트**: 자동 테스트 없음. 목 데이터로 `pnpm dev` 를 띄워 다섯 가지 문제 종류와 [잘 모르겠어요], 뒤로, 홈의 완료 표시를 눈으로 확인.
