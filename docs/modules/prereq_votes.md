# worker/concepts/prereq_votes.py

- **한 줄 설명**: 개념 지도 ④. "A를 알아야 B를 이해할 수 있나?"를 개념 쌍마다 독립으로 4번 묻고 다수결로 선수 관계를 정한 뒤, 사람 검토 파일로 확정한다 (#198, #203). proposals.py의 "2회 일치"를 넓힌 방식이다.
- **입력**: ③이 만든 `ConceptNode` 목록, 임베딩 유사도 행렬(없어도 됨), 사람 검토 파일 `worker/concepts/prereq_review.csv`(Git에 올림). 호출은 Haiku (`llm_client`로 월 한도·비용 기록, module=`concept_map`).
- **하는 일 ① 후보 쌍**: 모든 쌍을 묻지 않는다. 같은 카드에 같이 나온 쌍 → **설명에 서로 이름이 나오는 쌍** → 개념마다 임베딩이 가까운 이웃 3개(유사도 높은 순). 상한 400쌍. 설명 쌍(`definition_pairs`)은 "영업이익: 매출에서 비용을 뺀 이익"처럼 한쪽 `desc`에 다른 쪽 대표 이름·별칭이 나오는 쌍이다. 이름이 "…액"이면 "액"을 뗀 것도 찾고(매출액 → "매출"), "…률"은 떼지 않는다("수익"이 "수익과 비용"에 잘못 걸림). 설명에 나왔다고 꼭 선수는 아니어서("자사주 취득: 자기 주식을 사들이는 것"은 오히려 반대) 방향은 정하지 않고 후보로만 넣어 다수결로 다시 묻는다.
- **하는 일 ② 묻기와 다수결**: 쌍마다 4번 독립 호출한다. 답은 first / second / none이고 이유를 먼저 쓰게 한다. 호출마다 두 개념의 순서를 번갈아 바꾸고(원래 2번 + 바꾼 순서 2번), 답을 원래 방향으로 되돌려 센다. 한 방향이 3표 이상이면 선수 관계, 표가 갈리거나 none이 과반이면 넣지 않는다.
- **하는 일 ③ 사람 검토**: 줄마다 `pre, post`(대표 이름. 노드 id는 지도를 다시 만들면 바뀐다), `decision`, `votes`("3/4"), `note`. keep(남김) / drop(뺌) / add(다수결이 못 잡은 연결을 사람이 넣음) / 빈칸(아직 안 봄, LLM 결과 그대로 넣음). 새로 나온 LLM 연결만 빈칸 줄로 더하고(`merge_llm_edges`), 이미 있는 줄은 건드리지 않아 사람이 drop한 연결은 다시 나와도 계속 빠진다. 지도에 넣을 연결은 drop만 뺀 줄이다(`reviewed_edges`). 이름은 대표 이름 → 별칭 순으로 찾고, 별칭 때문에 여러 줄이 같은 노드 쌍이 되면 하나로 합친다: drop이 하나라도 있으면 빼고(keep / add와 엇갈리면 `prereq_review_conflicts`로 알림), keep / add가 있으면 사람 표, 아니면 가장 많은 LLM 표. 사람이 keep / add한 연결은 표를 `HUMAN_VOTES`(5)로 줘서 순환을 끊을 때 LLM 연결보다 나중에 빠진다. 지도에 없는 이름이 있는 줄은 따로 돌려준다.
- **출력**: `Prereq(pre, post, votes, total)` 목록과 개수 요약(쌍, 호출, 연결, 갈림, 관계 없음). 계획 6장의 `concept_prereq(pre_id, post_id, votes)`와 같은 모양이다.
- **실제 카드 결과 (2026-11-24)**: 후보 232쌍 × 4표 = 928회 → 연결 47 / 갈림 15 / 관계 없음 170, 비용 약 $0.12. 설명 쌍으로 새로 생긴 쌍은 1개(등락률 → 지수 기여도, 4/4). 사람 검토: keep 40 / drop 7 / add 2 (계약금액 → 매출액 대비, 시가총액 → 시가총액 비중). 순환으로 1개가 빠져 최종 42개.
- **주의할 점**: 선수 관계는 인과가 아니다 ("EPS를 이해하려면 순이익을 먼저 알아야 한다"는 배우는 순서). 프롬프트에도 그렇게 적었다. **4번인 이유**: LLM은 앞에 나온 쪽을 고르는 버릇(위치 편향)이 있다. 3번이면 원래 순서 2번 + 바꾼 순서 1번이라 버릇만으로 2:1이 나와 연결이 생기고, 4번이면 정확히 2:2로 상쇄된다. **다수결은 답이 안정적이라는 뜻이지 맞다는 뜻이 아니다.** 실제로 4/4 만장일치인데도 틀린 연결(발행주식 총수 → 자사주 취득)이 있어서 사람 검토를 둔다. 애매하면 뺀다: 잘못된 연결은 ready 규칙(#199) 때문에 학습자를 막지만, 빠진 연결은 순서를 강제하지 않을 뿐이다. 순환 끊기는 1-2 `prereq.dl`(`break_cycles`)이 맡고 build_map이 부른다.
