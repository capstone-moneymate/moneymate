# worker/concepts/datalog.py, worker/concepts/rules.dl

- **한 줄 설명**: 개념 사전의 판단 기준(영향·모호성·정답 경로)을 탐색 코드가 아니라 규칙 파일 `rules.dl`로 적고, 작은 Datalog 엔진이 사실(연결)에 규칙을 새 결론이 안 나올 때까지 적용한다(고정점).
- **왜**: 교수님 피드백 "결국 if문 반복 아니냐"와 멘토님 제안(「교수님 설득을 위한 기술 방향 정리」 4-3). 정적 프로그램 분석이 Datalog로 분석 규칙을 쓰고 고정점까지 계산하는 것과 같은 방식이다. 정답 기준이 코드 밖(CSV 사실 + 규칙 3줄)에 있어 읽고 검토하고 고치기 쉽다.
- **입력**: 규칙 글(`parse(text)`)과 사실 `{관계: {튜플}}`(`evaluate(program, facts)`). 개념 사전은 `graph.py`가 `causal_edges.csv`를 `edge(원인, 결과, ±1)`로 넣는다.
- **규칙 (`rules.dl`)**
  ```
  effect(X, Y, S) :- edge(X, Y, S).
  effect(X, Z, S1 * S2) :- effect(X, Y, S1), edge(Y, Z, S2).
  ambiguous(X, Y) :- effect(X, Y, 1), effect(X, Y, -1).
  ```
  예전 `graph.py`의 경로 탐색(for·if·재귀·되돌리기)이 하던 방향·모호성 판단을 이 세 줄이 정한다.
- **하는 일**: 문법은 쓰는 만큼만(관계 이름 소문자, 변수는 대문자·`_`, 정수·문자열 상수, 머리에서만 정수 곱, `%`·`//` 주석). 읽을 때 안전 규칙(머리 변수는 몸통에 있어야 함)을 검사한다. 계산은 **semi-naive evaluation**: 매 회차에 지난 회차에 새로 나온 사실(Δ)이 몸통에 하나 이상 들어간 조합만 다시 보고, 새 사실이 없으면 멈춘다. 부호가 ±1뿐이라 순환이 있어도 결론의 종류가 유한해 멈춘다.
- **출력**: `Result(relations, rounds)`. `graph.derive(g)`가 이것을 `Derived(effects, ambiguous, rounds)`로 바꿔 `effect()`·`ambiguous_pairs()`에 쓴다(연결이 같으면 캐시).
- **부정과 국면별 조건부 연결 (2026-11-18, #158)**: 몸통 원자 앞의 `!`는 "그런 사실이 없으면 참"이다. "B가 없으면 A"를 판단하려면 B를 먼저 다 알아야 하므로 규칙을 층으로 나눠(`stratify`) 아래 층부터 고정점까지 계산한다(층별 부정, stratified negation). "A가 없으면 A"처럼 부정이 순환에 걸리면 읽을 때 오류. 부정 원자의 이름 있는 변수는 같은 몸통의 긍정 원자에서 정해져야 하고(순서는 상관없다. 긍정을 모두 맞춘 뒤 부정을 본다), `_`는 "아무거나"라 `!p(X, _)`는 "X로 시작하는 p가 하나도 없음". 이걸로 멘토님 문서의 국면 규칙을 그대로 넣었다(`rules.dl` 4~6).
  ```
  overridden(X, Y, R) :- cond_edge(X, Y, _, R).
  edge_r(X, Y, S, R) :- edge(X, Y, S), regime(R), !overridden(X, Y, R).
  edge_r(X, Y, S, R) :- cond_edge(X, Y, S, R).
  effect_r(X, Y, S, R) :- edge_r(X, Y, S, R).
  effect_r(X, Z, S1 * S2, R) :- effect_r(X, Y, S1, R), edge_r(Y, Z, S2, R).
  ambiguous_r(X, Y, R) :- effect_r(X, Y, 1, R), effect_r(X, Y, -1, R).
  ```
  조건부 연결 사실은 `db/seeds/cond_edges.csv`(원인, 결과, 방향, 국면, note). 국면 사실은 `normal`과 이 파일에 나오는 국면들. `graph.effect(..., regime=)`를 안 주면 평상시라 예전과 같다. 실제 사전(조건부 연결 1개) → 규칙 2개 층, 11회차에 고정점. 기준금리 인하 → 국채 금리 → 성장주 가치평가: 평상시 ▲, 경기 침체 ▼.
- **정답 경로도 규칙으로 (2026-11-19, #170)**: Datalog 사실은 목록을 담을 수 없어서, 규칙은 "연결 A → B가 X → Z 경로 위에 있다"(`step`)를 결론으로 낸다(`rules.dl` 7~9). 사실 `concept(C)`는 `concepts.csv`의 개념 id다.
  ```
  reach0(Y, Y) :- concept(Y).
  reach0(X, Y) :- effect(X, Y, _).
  step(X, Z, X, B) :- effect(X, Z, _), edge(X, B, _), reach0(B, Z).
  step(X, Z, A, B) :- step(X, Z, _, A), edge(A, B, _), reach0(B, Z).
  ```
  국면별은 `reach0_r`·`step_r`로 같은 규칙을 국면 연결(`edge_r`·`effect_r`)에 적용한다. `graph.signed_paths`는 탐색하지 않고, `step` 결론의 연결만 시작 개념부터 이어 붙인다. 갈라지는 곳(경로가 둘 이상)에서는 모두 낸다. 그래서 어떤 개념이 정답 순서에 들어가는지는 규칙이 정한다. 손계산: a → b → c, a → d(d에서 c로 못 감)이면 a → c 경로 위의 연결은 a → b, b → c 둘뿐이다. 실제 사전은 경로가 있는 쌍 43개 중 5쌍이 경로 2개다(인플레이션 → 국채 금리·은행 마진·성장주, AI 투자·GPU 수요 → 반도체 실적). 모든 국면 × 모든 쌍에서 예전 탐색과 경로·순서·부호가 같다. 규칙이 17줄이 되어 CLI는 2개 층, 19회차에 고정점으로 출력한다(`python -m concepts.graph` 0.2초 안쪽).
- **주의할 점**: `effect()`는 매번 방향 결론과 `step`으로 만든 경로의 부호가 같은지 확인한다. 순환이 있는 사전에서는 엔진이 순환을 도는 영향까지 세서 어긋날 수 있어 오류를 낸다. `graph.load_graph()`는 순환을 검사하지 않는다. 막는 곳은 CLI다: 요약은 모호한 쌍을 세기 전에 `find_any_cycle()`(평상시와 모든 국면)로, `--from/--to`는 `effect()` 전에 그 국면의 `find_cycle()`로 확인하고 순환이 있으면 국면과 함께 출력하고 멈춘다. 기본 연결만 쓰는 `loader`(DB 시드)도 평상시 순환은 막는다. 조건부 연결은 국면마다 1차 근거가 따로 있어야 넣는다. 출제 파이프라인의 국면은 #174부터 삼의 법칙 지표(FRED SAHMREALTIME ≥ 0.5면 recession)로 코드가 정한다(regime.md). 탭 1 출제·검증과 탭 2 이유(#183, 큰손 쪽은 분기 말·ETF 쪽은 ETF 최신일 국면)에 쓰인다. 확정/경향 등급은 다음 이슈. 규모가 작아(개념 29개) 색인 없이 중첩 반복으로 맞춘다.
