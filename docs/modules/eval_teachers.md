# worker/eval/teachers.py

- **한 줄 설명**: 1-5 교사 세 가지 (#238). ① 고정 순서 ② 규칙만 ③ 튜터 에이전트(+ 제거 실험)를 같은 학습자·퀴즈 은행·BKT 로 돌린다.
- **입력**: 카드 범위·목표 개념, 가상 학습자, 퀴즈 은행 `Draw`, `MemMastery`(메모리 BKT: 사람2 `learner.bkt`와 같은 식, 값은 `params`로 받음, 기본은 앱의 값), 퀴즈 상한.
- **하는 일**: `fixed` — 개념 지도 순서(선수 관계를 안 봄)대로 돌아가며 용어 뜻, BKT 를 안 봄. `rules` — 배울 준비가 된(#199 ready) 개념 중 BKT 알 확률이 가장 낮은 것, 종류는 알 확률로(0.5 미만 용어 뜻 / 0.8 미만 사례 분류 / 그 이상 칩 빈칸), 목표가 모두 0.95 를 넘으면 끝. `agent` — `tutor.agent`(Opus) 그대로, 퀴즈는 은행에서(`quiz_maker`), 상한은 세션마다(`max_quizzes`). 제거 실험: `no_bkt`(알 확률을 늘 처음 값으로 보여 줌), `no_prereq`(선수 관계 없는 지도). 확신은 학습자가 낸 그대로 넘긴다(본 비교는 학습자가 확신을 내지 않음). 세 조건 모두 답한 뒤 해설을 보여 주고(학습자가 배울 기회), 틀리면 고정·규칙도 설명을 한 번 보여 준다(에이전트는 설명을 스스로 고른다). `final_test` — 목표 개념마다 시험용 퀴즈로 배우지 않고 답만 한다(따로 씨앗).
- **출력**: `Episode`(낸 퀴즈 수, 설명 수, 숨긴 상태로 목표를 다 알게 된 시점 `mastered_at`, 퀴즈마다 개념·종류·정답·원래 알았는지·배웠는지).
- **주의할 점**: 지표는 BKT 가 아니라 숨긴 상태로 잰다. 에이전트만 Opus 를 불러 비용이 든다(세션 하나 약 $0.06). 고정 순서는 범위를 한 바퀴 돌도록 용어 뜻 퀴즈가 하나도 없으면 끝없이 돌지 않고 QuizError 를 낸다.
- **테스트**: `cd worker && python -m pytest tests/test_eval.py -q` (BKT 가리기, 고정 순서·틀리면 설명, 규칙이 선수 관계 순서·낮은 것부터·다 알면 끝, 종류 규칙, mastered_at, 에이전트 루프(가짜)가 설명·답·확신을 넘김, 시험은 안 가르치고 씨앗이 따로).
