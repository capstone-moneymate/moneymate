# worker/compute/source_select.py

- **한 줄 설명**: 기술확정안 "1차 자료 선별"(거르기 → 시장 주목도 0~4점 → 고르기 최대 3건)을 DB·네트워크 없는 순수 함수로 옮긴 것.
- **입력**: DART 보고서명 / 8-K 항목, 발표 시각, 국내 전 종목 그날 표(`prices.fetch_kr_daily`)와 직전 252거래일 거래량, 지수·미국 종목의 과거 252일 값, 후보 목록(`Candidate`).
- **하는 일**: ① `dart_category`·`sec_8k_category` 거르기 (정정·임원 소유·대량보유·자율공시 제외). ② `reaction_day`: 장 마감(KR 15:30 KST, US 16:00 ET) 전이면 당일, 후면 다음 거래일. ③ `cross_section_scores`: 비정상 거래량 = 그날 ÷ 직전 252일 평균, 전 종목 중 상위 10% 1점·5% 2점 + 수익률 양끝 10% 1점·5% 2점. ④ `own_history_score`: 지수·미국 종목은 자기 과거 252일 중 순위(변형). ⑤ `select`: 유형 3 1건 먼저 → 새 테마·유형 → 순위대로 → 모자라면 가격 카드.
- **출력**: 점수 표(ticker, abn_volume, vol_score, ret_score, score), 고른 `Candidate` 최대 3개.
- **팀 확인이 필요한 변형 3개**: (1) DART는 접수 시각을 주지 않아 `reaction_window_date_only`로 당일·다음 거래일을 둘 다 보고 큰 점수를 쓴다 (MacKinlay 1997 사건 기간). (2) 지수·미국 종목 거래량은 "반응일 거래량이 과거 252일 거래량 중 몇 번째인지"로 단순화했다 (날마다 비정상 거래량을 다시 내려면 504일치 필요). (3) 직전 252거래일이 다 차지 않은 종목(신규 상장)은 순위에서 빼고 0점.
- **주의할 점**: 공급계약 의무 기준(5%·2.5%·10%) 이상인지는 "자율공시"가 아닌 것으로 판정한다 (기준 미만은 자율공시로 내므로). 거래소 공시규정 시행세칙으로 재확인 필요. `start_concept`·`card_type`은 3주차 classify 결과로 채운다. 경계: 20종목이면 q=순위/20, 위·아래 각 1개 2점, 그다음 각 1개 1점.
