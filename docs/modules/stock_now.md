# worker/generate/stock_now.py

- **한 줄 설명**: 탭 2 종목 상세 카드 ③ "지금은". 큰손이 공시 기준일(13F 분기 말)에 보유를 바꾼 뒤 무슨 일이 있었는지를 사실로 보여 주고, 카드 ② 이유가 오늘 탭 1에서 배운 개념과 이어지는지 알려 준다.
- **입력**: 종목(`ticker`, `name`), 공시 기준일, 카드 ② 이유(`reasons.Reason` 목록, 경로 포함). DB에서 `prices`(기준일 앞 10일~오늘 종가), `raw_sources`(그 종목의 기준일 뒤 자료 최근 3건), `cards`·`steps`(오늘 이하 가장 최근 published 탭 1 카드의 시작 개념·concept_ids)를 읽는다. 실행: `cd worker && python -m generate.stock_now NVDA 2026-09-30 [--no-llm]`.
- **하는 일**: "기대가 맞아가고 있다"를 LLM이 판정하면 평가·예측에 가까워져서 판정하지 않고 사실을 나란히 놓는다(2026-11-16 C 결정). ① 기준일 이후 주가: 기준일 이하 마지막 종가 → 최근 종가, 수익률은 코드 계산(소수 둘째 자리. 종가도 표시용으로 둘째 자리, yfinance 원본 1154.2900390625가 문장에 그대로 나왔다) ② 기준일 뒤 자료 최대 3건과 numbers 8개(전년동기 증감률·방향·규모 비율을 먼저, 전기대비는 뒤. JSONB가 키 순서를 바꿔서 앞에서 자르면 증감률이 빠졌다) ③ 이유 경로의 개념 중 오늘 탭 1 카드가 다룬 개념(같은 개념은 첫 이유에만) ④ Haiku가 위 사실만으로 2~3문장. 코드 검사: 입력에 없는 숫자(부호·쉼표·앞자리 0·끝자리 0 무시), 금지 표현(B의 find_banned), 300자 초과. 걸리면 1번 고쳐 쓰게 하고, 그래도 안 되면 문장 없이 사실만 남긴다.
- **출력**: `StockNow(base_date, price, later_sources, linked, text, errors, calls)`. `to_json()`이 `stock_reasons.now_view`에 넣을 모양(snake_case, 예시는 reasons.md "저장 모양")이다. 저장은 `reasons.save()`가 카드 ②와 한 줄로 한다.
- **주의할 점**: 저장 테이블은 A의 004 `stock_reasons`(P19). run_daily(13F 분기 갱신 때) 연결과 A의 종목 상세 API 연결(#101)이 남았다. 13F 종목은 대부분 미국이라 `prices`에 그 티커가 있어야 한다(`collectors/prices.py us <티커> <시작일>`). 숫자 검사는 글자 비교라 입력 어딘가(날짜 포함)에 있는 숫자면 통과한다(예: 기준일 9/30의 30). 단위를 바꿔 쓴 숫자(백만원 → 억원)는 입력에 없어서 걸린다. 오늘 카드는 published만 본다(pending은 아직 사용자에게 안 보이므로).
- **테스트**: `cd worker && python -m pytest tests/test_stock_now.py -q` (손계산: 기준일이 휴장이면 그 앞 종가, 100 → 112.5 = +12.5%, 3 → 3.5 = 16.67%, 기준일 앞뒤 값이 없으면 None, 경로 개념 연결과 중복 제외, numbers 우선순위, 숫자 검사 통과·실패, 금지 표현, 가짜 Haiku로 문장·고쳐 쓰기 후 포기·데이터 없으면 호출 안 함·--no-llm·잘린 응답, `reasons.save` upsert 인자와 published·rejected, 종목 단위 방향 규칙). 2026-11-16 로컬 DB로 `222800(심텍) 2026-09-30 --no-llm`을 돌려 쿼리 확인(9/30 150,300 → 11/16 108,100 = -28.08%, 11/3 실적·시설투자 공시). 2026-11-16 MU(2분기 기준)로 run_reasons 생성과 run_daily 갱신(refresh_now_views)을 실제로 확인: "기준일 2026-06-30 종가는 1154.29달러였어요. 2026-11-13 종가는 778.31달러로, 같은 기간 수익률은 -32.57%예요. 2026-09-30에는 마이크론 8-K 공시가 있었어요." 오늘 published 탭 1 카드가 없어 linked 는 비어 있었다.
