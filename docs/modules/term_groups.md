# worker/concepts/term_groups.py

- **한 줄 설명**: 개념 지도 ③. 로컬 임베딩으로 뜻이 같은 용어("EPS"/"주당순이익")를 개념 노드 하나로 묶는다 (#198).
- **입력**: concept_map.py ①②가 만든 `Term` 목록, 임베딩 함수(`load_encoder(모델 이름)`, 글 목록 → 정규화된 벡터), 기준값. 설치는 `pip install -e ".[embed]"` (sentence-transformers + torch). 모델은 처음 한 번 Hugging Face에서 내려받는다.
- **하는 일**: 용어 글자만 임베딩해서 코사인 유사도 행렬을 만들고, **완전 연결**로 묶는다. 가장 비슷한 두 묶음부터 합치되, 두 묶음 사이의 **모든 쌍**이 기준값 이상일 때만 합친다. 한 쌍만 비슷해도 합치면(단일 연결) "기준금리 인상 ~ 금리 인상 ~ 금리 인하"처럼 사슬로 이어져 반대말까지 합쳐지기 때문이다.
- **출력**: `ConceptNode(label, desc, aliases, card_ids)`. 대표 이름은 가장 많은 카드에 나온 용어이고, 같으면 먼저 나온 용어다. 나머지 용어는 별칭이 된다. 계획 6장의 `concept_nodes(id, label, aliases)`와 같은 모양이다.
- **기본값**: 모델 `nlpai-lab/KURE-v1`, 기준값 0.70 (`DEFAULT_MODEL`, `DEFAULT_THRESHOLD`). 2026-11-23 `compare_embeddings.py`로 후보 4개를 비교한 결과다 (인과 사전 글 100개, 모델마다 0.50~0.95 중 F1이 가장 높은 기준값). KURE-v1 F1 0.689·정밀도 0.912, bge-m3 0.676·0.910, ko-sroberta 0.672·0.677, e5-base 0.546·0.767. KURE-v1과 bge-m3의 차이는 작다. e5-base는 "기준금리 인상"과 "인하"를 0.97로 봐서 뺐다. 정밀도를 앞에 둔 이유: 못 묶으면 같은 개념이 두 칸으로 남을 뿐이지만, 잘못 묶으면 다른 개념이 섞인다. 한계: 약어는 거의 못 묶는다 ("EPS"/"주당순이익" 0.37, "캐파"/"생산능력" 0.35). 재현율 0.553의 주된 이유다.
- **주의할 점**: 설명(desc)은 임베딩하지 않는다. 카드마다 문체가 달라서 유사도를 흔든다. 임베딩은 LLM이 아니라서 비용이 없고 같은 입력이면 같은 결과가 나온다. 기준값과 모델은 `scripts/compare_embeddings.py`로 인과 사전 별칭을 정답 삼아 고른다. 묶인 결과는 정답이 아니라 후보라서 사람이 훑어본다.
- **테스트**: `cd worker && python -m pytest tests/test_term_groups.py -q` (모델 없이 손으로 만든 유사도: 완전 연결이 사슬로 잇지 않음, 기준값에 따른 묶음, 0개·1개, 쌍 정밀도·재현율 손계산, 대표 이름 고르기와 동점, 가짜 임베딩 함수).
