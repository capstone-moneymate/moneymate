# worker/run_daily.py

- **한 줄 설명**: 하루 파이프라인. 수집 → 계산 → 선별 점수 → 분류(Haiku) → 고르기 → 출제(Sonnet, 검증 포함) → pending 저장 → 토론(Haiku) → 탭2 지금은(Haiku)을 한 번에 돌린다.
- **입력**: 기준 거래일(`--date`, 없으면 오늘 이전 가장 최근 국내 거래일). `--skip-collect`(수집 건너뜀), `--no-llm`(선별 점수까지만, 비용 0), `--schedule`(APScheduler로 매일 08:00 KST). 실행은 `cd worker && python run_daily.py`.
- **하는 일**: ① 수집·계산: 국내 전 종목·지수 가격(`prices`), 1차 자료 DART·거시·8-K(`sources`, 8-K는 최근 겹침 결과의 미국 종목만), ETF 구성종목(`etf_holdings backfill <기준일>`: 기준일부터 빠진 날만 받아 평소엔 today 와 같고, 다시 돌리거나 전날 수집이 실패해도 채워진다. #87 리뷰), ETF 추세(`etf_trend --date --save`). ② 선별 점수: 기준일 직전 거래일 다음 날부터 기준일까지 나온 `raw_sources` 중 아직 카드가 되지 않은 자료(`card_sources`에 없는 것, #87 리뷰)마다 반응일(시각 있으면 `reaction_day`. 지수 자료는 KS11·KQ11이면 국내, IXIC·US500이면 미국 마감 시각으로 본다. DART처럼 없으면 당일·다음 거래일 중 큰 점수)의 거래량·수익률 점수를 `source_select`로 계산한다. 국내 종목은 그날 전 종목 순위(`cross_section_scores`), 지수·미국은 자기 과거 252일(`own_history_score`). ③ 1점 이상 중 상위 10건만 classify, `select`로 최대 3건, 각각 `compose`(검증·pending 저장). ④ 토론(A의 `generate/debate.py`, 2026-11-17 #142): 출제한 카드가 있으면 그 card_id 마다 판단해보기 단계를 읽어 Haiku 로 낙관 1번·비관 1번(검사 실패 시 고쳐 쓰기)을 부르고 `card_debates`에 저장한다(P21, 실측 카드당 약 $0.0004). 결과는 "published n/m". 판단 단계가 없는 카드는 건너뛰고, 토론이 rejected 여도 채점은 토론 없이 되므로 단계 실패로 보지 않는다(DB·API 예외만 실패). 화면에 따로 보이지 않고 판단 채점의 "더 생각할 점" 재료로만 쓴다.
- **출력**: 단계별 OK/ERR 출력, `logs/run_daily.jsonl`에 한 줄(기준일, 단계 결과, 만든 card_id). 실패한 단계가 하나라도 있으면 종료 코드 1.
- **주의할 점**: 같은 `--date`로 다시 돌려도 이미 카드가 된 자료는 다시 출제하지 않는다. 그래서 토론 단계가 중간에 실패한 카드는 다시 돌려도 채워지지 않는다. 그때는 `python -m generate.debate --date <카드 날짜>`(토론 없는 카드만)로 따로 채운다. 단계 하나가 실패해도(예외든 종료 코드 1이든) 나머지는 계속 돌린다. ETF 수집기가 1을 돌려주면 실패로 본다(B 요청 4). DART는 다음 거래일 점수까지 보려면 하루 늦게 다시 돌려야 한다(08:00 실행이면 당일 점수만 있음, 팀 확인 필요). 13F·겹침 계산과 카드 ② 이유는 분기마다라 여기에 넣지 않았다(이유는 `scripts/run_reasons.py`). ⑤ 탭2 지금은(2026-11-16): `--no-llm`이 아니면 출제 뒤에 가장 최근 분기의 published `stock_reasons` 종목마다 미국 가격을 기준일 10일 전부터 받고 카드 ③(`now_view`)만 다시 만든다(Haiku). 종목 하나가 실패해도 나머지는 갱신하고 단계는 실패로 남긴다. 결과는 "갱신 n/m종목" 문자열이다(run_step 은 int 를 종료 코드로 본다). `--no-llm`이면 문장 없는 카드 ③으로 덮어쓰지 않게 건너뛴다. 차트 종목 카드(2026-11-21, 탭 1 차트 규칙, docs/modules/stock_move_card.md): 고른 자료에 종목 카드(국내·미국 ticker)가 없으면 점수 최하위 카드를 빼고(3장 미만이면 빼지 않고) 그날 시장 반응 1위 국내 종목의 움직임 카드를 넣는다. 자료가 하나도 없는 날에도 이 카드는 만든다. 출제 뒤 `ensure_chart_card` 가 종목 카드 중 점수 1위를 `cards.model_info.select.chart = true` 로 표시하고, 종목 카드를 하나도 못 만들었으면(출제 실패) 다음 반응 종목으로 한 번 더 만든다. 차트 종목 카드 자료(`source_type = 'price'`)는 선별 점수 대상에서 뺀다. `--schedule`은 프로세스가 떠 있는 동안만 돈다(배포 때 컨테이너로). APScheduler 의존성을 pyproject에 추가했다(3.x).
