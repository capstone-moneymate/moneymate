- `ReasonsCard.tsx`: 제목은 서버의 `headline`이다. 이유는 가로로 넘겨 보고(scroll-snap, 한 장이 85% 너비), 이유마다 제목·본문·인과 뼈대(배운 개념 강조, ▲ 올리는 힘 / ▼ 누르는 힘)·근거 자료를 보여 준다. 근거는 제목(원문 링크, 새 창)·날짜·출처만 보여 주고 기사 본문은 보여 주지 않는다. 근거 번호는 `evidenceNumbers.ts`가 이유 순서대로 처음 나온 자료부터 1, 2, 3…으로 다시 매긴다(C의 번호 4, 11 → 1, 2. 같은 자료는 같은 번호). 경로에 배운 개념이 있으면 "내 지도에 있어요" 배지를 붙인다. `reasons`가 null이면 대체 문구만 보여 주고 카드 ③은 숨긴다.
