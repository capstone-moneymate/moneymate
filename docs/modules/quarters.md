# worker/common/quarters.py

- **한 줄 설명**: 13F 분기 말(3/31, 6/30, 9/30, 12/31) 날짜를 계산하는 공통 함수.
- **입력**: `date` 또는 `'YYYY-MM-DD'` 문자열.
- **하는 일**: `prev_quarter_end`는 앞선 분기 말, `latest_quarter_end`는 그날 이하의 최근 분기 말, `parse_quarter_end`는 명령줄 인자를 읽고 분기 말이 아니면 오류를 낸다.
- **출력**: `date`.
- **주의할 점**: 13F 수집·변화 계산·겹침 판정이 같이 쓴다. 날짜만 다루고 시간대는 없다(분기 말은 미국 날짜).
- **테스트**: `python -m pytest tests/test_quarters.py -q` (6/30 → 3/31, 3/31 → 전년 12/31, 8/14 → 6/30, 6/29는 오류).
