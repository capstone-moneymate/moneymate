- **한 줄 설명**: 탭 3 마이페이지 홈(시안 26, `/mypage`). 연속 학습, 숫자 3개, 나의 인과 지도 요약 카드, 다시 보는 개념(종합 정답률 낮은 순)을 보여 준다 (#120).

- **하는 일**: ① 위쪽 문구: 오늘 풀었으면 "오늘도 한 걸음 성장했어요", 아니면 "나아가 볼까요?" ② 연속 학습 배너("N일 연속 학습 중이에요", 0이면 시작 안내) ③ 숫자 3개: 개념 학습 N개, 종합 정답률 %, 판단 시뮬레이션 N회 ④ 인과 지도 카드: 배운 개념 수, 같은 테마 안 연결 수(지도 첫 화면 기준), "지도 열기 ›". 테마별 개수 칩은 테마가 늘면 지저분해져 뺐다(2026-11-16 B 결정) ⑤ 다시 보는 개념: 서버 순서 그대로 5개, "전체 보기"로 나머지. 줄 = 이름, `테마 · 정답률 N%`, ›. 푼 횟수·맞힌 횟수는 보여 주지 않는다(2026-11-16 B 결정). 누르면 `/mypage/map?focus=개념id`.
