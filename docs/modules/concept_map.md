# worker/concepts/concept_map.py

- **한 줄 설명**: 퀴즈 앞 "개념" 단계 용어로 개념 노드와 선수 관계를 자동으로 만든다 (계획 1-1, #198). 탭 1 인과 사전과는 별개이고 그 사전은 고치지 않는다.
- **입력**: DB의 `steps`(kind=`concept`의 `content.terms` = `[{term, desc}]`)와 카드 슬라이드 글(카드 제목, 장마다 `heading`·`body`·`facts.label`. 숫자 값 `facts.value`는 뺀다). 반려된 카드는 뺀다. 사람 검토 파일 `worker/concepts/term_review.csv`(Git에 올림). 실행은 보통 `build_map`이 하고, 단독으로는 `cd worker && python -m concepts.concept_map` (`--extract`면 ②까지, `--limit N`은 앞 N장만, `--save`는 파일 저장). ②는 카드마다 Haiku 1회 (`llm_client`로 월 한도·비용 기록, module=`concept_map`).
- **하는 일 ①**: 용어를 카드 순서대로 읽고, 띄어쓰기·대소문자·괄호 안 글자만 다른 용어("기준 금리"/"기준금리", "eps"/"EPS", "지수 기여도(%p)"/"지수 기여도")를 하나로 합친다 (`term_key`). 괄호 규칙은 2026-11-24 실제 카드에서 같은 뜻으로 확인된 쌍이 모두 괄호만 다른 표기여서 넣었다 (term_groups.md 기준값 항목). 용어마다 나온 카드 id를 모으고, 다른 카드에서 쓴 다른 설명은 `descs`에 남긴다. 뜻이 같은 다른 말("EPS"/"주당순이익")은 여기서 묶지 않는다 (③ 임베딩 담당).
- **하는 일 ②**: 카드마다 그 카드의 슬라이드 글, 이 카드의 기존 용어, 지도 전체 용어 이름을 주고 빠진 용어를 받는다 (JSON 스키마: `term`, `same_as`, `desc`. `same_as`는 지도 이름 중에서만 고르게 enum). 처음에는 1차 자료 제목을 줬지만 실제 제목이 "MICROSOFT CORP 8-K Item 2.02" 같은 모양이라 카드 글로 바꿨다. 코드가 거른다: 빈 값, 20자 초과, 숫자만, **카드 글에 글자 그대로 없음**(띄어쓰기·대소문자 무시, 괄호는 남기는 `squash`), 이 카드에 이미 있음, 금지 표현, 카드당 5개 초과.
- **② 사람 검토**: ② 결과는 바로 지도에 넣지 않고 `term_review.csv`의 빈칸 줄(후보)로 더한다. 실제 카드에서 절반 가까이가 문장·구절("소각하면 주식 수가 줄어요")이었기 때문이다. 사람이 `decision`에 keep(새 용어) / drop(뺌) / same(`same_as` 용어의 다른 표기)을 적은 것만 `apply_review`가 지도에 넣는다. keep 용어는 카드 글에 글자 그대로 나온 카드에 코드가 잇는다 (`cards_with`, LLM 없음). 다시 뽑아도 사람이 drop한 용어는 들어가지 않고, 같은 결과가 여러 번 들어가지 않는다. 사람이 용어를 직접 줄로 넣을 수도 있다 (2026-11-24 종가). 지금 keep 15 / drop 11 / same 1.
- **same_as 확인**: LLM이 "같은 뜻"이라고 해도 임베딩 유사도가 `SAME_AS_MIN`(0.80) 이상일 때만 받는다 (`same_check`, term_groups.md). 실제 카드에서 LLM이 "자기주식 = 자사주 취득"(0.750, 가진 주식 / 사는 행동)이라고 잘못 답해서 넣었다. 두 신호를 다 통과한 같은 뜻은 same 줄로 자동으로 적힌다.
- **출력**: `Materials(terms, sources, texts)`. 개수와 버린 용어·이유를 출력하고, `--save`면 `logs/concept_map/materials.json`에 저장 (Git에 올라가지 않음).
- **주의할 점**: 기사 본문은 저장하지 않으므로 1차 자료 본문은 쓰지 않는다. ②는 proposals.py처럼 2회 일치를 보지 않는다. 대신 "카드 글에 있는 말인가"를 코드가 확인해서 LLM이 지어낸 용어는 남지 않고, 초보자가 배울 용어인지는 사람이 검토 파일에서 정한다. `desc`는 LLM이 쓴 뜻풀이라 정답으로 쓰지 않는다. ①과 검토 반영은 같은 DB·같은 검토 파일이면 돌릴 때마다 결과가 같다 (②를 다시 돌리면 후보는 달라질 수 있다).
