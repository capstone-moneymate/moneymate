- **2026-11-27 목표 먼저 vs 선수 먼저 (#285, 과거 기록 있음, 상한 6, 칸마다 16세션)**: 튜터 기본 규칙을 "목표 개념을 먼저 묻고, 맞히면 그 목표의 선수 개념은 건너뛰고, 틀리면 모르는 선수 개념으로 내려가 확인·설명한 뒤 목표를 다른 종류로 다시 묻기"(`target_first`)로 바꾸고, 예전 규칙(`prereq_first`: 선수 개념을 모르는 목표는 나중에)과 같은 코드·같은 입력으로 비교했다. 입력 지문 `b8cabd47ea49`(#263 지도 확장 뒤)라 11/25 숫자와 섞지 않는다. 두 쪽 모두 #282(상태 같이 넘기기)·#284(설명 세 칸) 뒤 튜터다. 고정·규칙도 같은 지문으로 다시 돌렸다.
